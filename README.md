# NGS 武器どっち？

PSO2 ニュージェネシス（NGS）の武器を**ざっくり威力比較**するブラウザツールです。
サーバー不要・単一HTMLファイルで動作します（データ内蔵）。

**👉 使い方: `index.html` をブラウザで開くだけ**（Chrome / Edge 推奨）

## 計算式

```
威力 = 武器攻撃力 × 潜在能力Lv倍率 × プリセット能力倍率
```

- **単純な威力倍率のみ**の計算です。クリティカル率や各種実倍率は省いています（ざっくり比較用）
- 武器攻撃力はシリーズ選択で **強化値+100 の値**が自動入力（手入力で任意の強化値にも変更可）
- 潜在能力は武器固有（付け替え不可）なので、シリーズ選択で自動セット。Lv1〜6 選択可
- プリセット能力は「条件込み実効威力%」で計算：
  - アタック（無条件）＋8〜10%
  - ウィクス（弱点部位攻撃時）＋10.16〜14.24%
  - アンウィクス（非弱点部位攻撃時）＋7.1〜17.3%
  - ブラストル（PB発動時）＋10.21〜22.08% ／（PB非発動時）＋7〜9%
  - アバンダク（特殊能力20種時の最大）＋4.55〜12.2%
  - クリ系（テルミナ／フェタル）はクリ発生率・クリ威力であって直接威力ではないため対象外
- 比較表は威力降順ソート + 1行目を基準にした差分%表示

## 対応武器（最新ブロック 12シリーズ）

リイズ／レアレンス／カイズ／レクシオ／リュウゲンセイ／ショウゲンセイ／コウゲンセイ／アルバラディオ／アルセ／リフラディオ／スプラディオ／エピス・イリニオンⅣ

※ 追輝の型・幽豪の型・極式・堅気系は wiki 未検証のため Lv1〜5で「威力？」表示（Lv6のみ対応）
